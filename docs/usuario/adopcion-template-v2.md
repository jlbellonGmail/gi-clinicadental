# Adopción Template v2.0.0

El circuito nuevo organiza cada cambio en una work unit aislada. Planner
prepara el plan, Builder implementa y Reviewer audita de forma independiente.
La profundidad puede ser LIGHT, STANDARD o FULL según el riesgo.

La adopción no cambia el sitio ni sus datos. El merge sigue siendo una decisión
humana y esta unidad no publica ni despliega.

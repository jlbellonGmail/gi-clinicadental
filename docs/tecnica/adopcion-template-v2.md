# Adopción Template v2.0.0

La adopción incorpora gobernanza, evidencias y lifecycle sin modificar la
landing, API, Supabase, SMTP ni Vercel. La procedencia exacta es
`v2.0.0@f5d4b6cc029c34c0d0c05831bfd28134276fa167`.

Las unidades nuevas usan Planner → Builder → Reviewer, ASSESS y SDD adaptativo.
Los runs históricos conservan el contrato legacy. `.agentic` es la fuente
canónica y los adaptadores no deben editarse como normas independientes.

MCP queda declarado pero vacío. La auditoría independiente OpenCode y CI
remoto son verificaciones posteriores a esta implementación local.

Política de Privacidad

Versión: v1-2026-08-20

0. Aviso: este sitio es una demostración técnica

Sonríe más no es una clínica en funcionamiento. Este sitio es una demostración técnica y de portfolio: la clínica, sus servicios y sus datos de contacto son un ejemplo construido para mostrar cómo funciona el circuito de captación de solicitudes de principio a fin.

No ingreses datos personales reales ni información clínica o de salud en el formulario. Nadie va a contactarte para coordinar una atención médica, porque no hay un equipo clínico detrás. Si querés probar el formulario, usá datos de prueba.

El resto de esta política describe con exactitud qué hace el sistema con lo que se envía, porque el comportamiento técnico que se describe es real: los datos efectivamente se guardan y se envían correos automáticos.

1. Finalidad

Lo que completás en el formulario de este sitio (nombre, correo electrónico, servicio de interés y el mensaje que quieras agregar) se registra con una única finalidad: demostrar el funcionamiento del circuito de captación de solicitudes — que el envío se guarde y que se emitan los correos automáticos correspondientes.

No se usan estos datos para ningún otro propósito distinto al descrito aquí, y no existe una actividad comercial ni clínica detrás de este formulario.

2. Datos almacenados

Cuando enviás el formulario, se almacenan los siguientes datos:

  • Nombre completo.
  • Correo electrónico.
  • Teléfono (si en el futuro el formulario lo solicita; hoy este campo no se recolecta).
  • Servicio de interés seleccionado.
  • Mensaje opcional que hayas escrito.
  • Fecha y hora en que se recibió tu solicitud.
  • Estado de seguimiento comercial de tu solicitud (por ejemplo, si ya fue contactada o está pendiente).
  • El registro de que diste tu consentimiento y la versión de esta política que aceptaste al enviar el formulario.

3. Responsable del tratamiento

No hay una persona jurídica constituida detrás de este sitio: no existe una clínica ni una empresa responsable, porque se trata de una demostración técnica y no de un servicio en operación.

El único canal de contacto de esta demo es sonriamas-contactos@nextgia.io. Escribí a esa dirección para cualquier consulta sobre este sitio o sobre los datos que hayas enviado.

Esta sección se completará con la identificación fiscal y el domicilio legal correspondientes si el proyecto pasa alguna vez a operar como un servicio real. Mientras tanto, no se declara ninguna entidad responsable, precisamente para no afirmar algo que no existe.

4. Destinatarios

Tus datos son accedidos únicamente por:

  • Quien mantiene esta demostración técnica, a través del buzón sonriamas-contactos@nextgia.io, que recibe el aviso de cada solicitud enviada.
  • Supabase, el proveedor de base de datos donde se almacenan los registros.
  • DonWeb, el proveedor de correo SMTP utilizado como intermediario técnico exclusivamente para el envío de los correos automáticos asociados a tu solicitud.

No se venden ni se comparten tus datos con terceros ajenos a este proceso.

5. Plazo de conservación

Los registros se conservan mientras esta demostración siga activa, y se eliminan cuando la demo se dé de baja o cuando vos lo pidas, lo que ocurra primero.

No existe un plazo de conservación comercial porque no hay una actividad comercial detrás: no se hace seguimiento de ventas ni se reutilizan los envíos para ninguna otra cosa.

6. Procedimiento de acceso, rectificación y eliminación (ARCO)

Como titular de tus datos, tenés derecho a solicitar acceder a la información que almacenamos sobre vos, pedir que se corrija si está desactualizada o es incorrecta, o solicitar su eliminación.

Para ejercer cualquiera de estos derechos, escribinos a sonriamas-contactos@nextgia.io, indicando el correo electrónico con el que enviaste tu solicitud para que podamos identificar tus datos.
